## 2. 软件主要功能

1. 建立穿戴甲商品款式和唯一 SKU，保存结构化颜色、元素、纹理、甲型、长度、肤色和避免项。
2. 从自然语言描述或上传图片创建款式；可选使用多模态 LLM 识别，但结果必须通过结构化校验。
3. 管理款式参考图、2×5 款式图、十甲裁剪、手模底图和逐甲槽位素材。
4. 为商品图、佩戴图、上架主图和肤色/视角试戴矩阵构造版本化 Prompt 和请求参数。
5. 创建持久化 AI 生成任务，执行幂等去重、依赖控制、输入快照、成本估算和预算限制。
6. 使用进程内 Worker 并发执行任务，调用 OpenAI 兼容图片接口，分类失败并指数退避重试。
7. 保存任务尝试、实际输入摘要、构建指纹、生成结果、费用和错误信息。
8. 对生成图执行本地自动 QA、可选视觉 LLM 建议性 QA 和人工复核。
9. 对候选生成版本进行谱系追踪、对比选择和局部修正。
10. 汇总任务成功率、失败原因、重试、费用、QA 和 SKU 完成度。
11. 导出 Shopify 图片素材包、manifest 和 CSV；或把审核通过的试戴资产版本化发布到 Cloudflare R2/D1。

## 3. 软件技术特点

- 单体 FastAPI + SQLite WAL + 进程内线程 Worker，减少单机部署依赖。
- 显式任务状态机和人工复核状态机，禁止非法状态跃迁。
- SQLite `BEGIN IMMEDIATE` 原子领取任务、预算预留和关键业务写入。
- 幂等键避免重复任务；成功任务重新生成时创建新版本而非覆盖。
- 生成任务创建时保存不可变输入快照，执行前重新哈希实际发送输入并校验一致性。
- SHA-256 内容寻址素材存储，避免素材路径变化掩盖内容变化。
- 任务谱系共享自动后代次数和金额预算，防止自动重生成/修正形成无界循环。
- Provider 错误分类、指数退避、崩溃恢复、依赖失败传播和原子文件写入。
- 自动 QA 与人工审核正交；导出和发布采用默认拒绝门禁。
- R2 先写对象、D1 再 UPSERT 元数据，并用本地发布版本账本记录部分失败。
- API Key/Token 在日志和读取接口中只展示指纹/末四位；出站 URL 有 SSRF 防护。
- 执行记录保存运行时代码树与依赖指纹，便于追溯哪一版代码生成了结果。

## 10. 运行环境

- Python 3.12+；或 Docker 运行 `python:3.12-slim` 镜像。
- FastAPI、Uvicorn、SQLite、Pillow、httpx、Pydantic。

- 持久化数据目录需要写权限。
- 图片/LLM 能力需要配置可用的 OpenAI 兼容服务；发布能力需要可选 Cloudflare R2/D1 配置。

## 11. 软件架构

架构类型：浏览器/服务器（B/S）单体应用。  
前端：无独立框架和构建步骤的原生管理页面。  
后端：FastAPI REST API。  
任务层：同进程线程 Worker + SQLite 持久队列。  
数据层：SQLite + 本地内容寻址文件存储。  
外部集成：OpenAI 兼容图片/Chat 接口；可选 Cloudflare R2/D1；本地 Shopify 素材包导出。  
部署拓扑：单实例；代码文档明确不支持多实例共享 SQLite。
